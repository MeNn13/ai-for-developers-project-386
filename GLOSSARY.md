# Календарь звонков

Сервис бронирования в календаре одного владельца: гость занимает свободный слот,
владелец видит предстоящие встречи. Глоссарий фиксирует слова, которыми проект
называет участников, время и поверхности.

## Роли

**Владелец**:
Единственный человек, чей календарь открыт для бронирования. Задан заранее,
учётной записи не имеет.
_Avoid_: пользователь, админ, хозяин

**Гость**:
Человек, который бронирует встречу в календаре владельца. Указывает только имя,
учётной записи не имеет.
_Avoid_: клиент, пользователь, посетитель

## Календарь и запись

**Тип встречи**:
Шаблон встречи: название, описание и длительность. Гость выбирает тип прежде, чем
выбрать слот.
_Avoid_: услуга, событие, звонок

**Встреча**:
Занятый интервал календаря вместе с типом встречи и именем гостя.
_Avoid_: запись, бронь, событие

**Бронирование**:
Действие гостя, закрепляющее свободный слот за ним. Результат бронирования —
встреча.
_Avoid_: запись, резервирование

**Слот**:
Интервал времени, который гость может занять. Длительность слота равна
длительности выбранного типа встречи.
_Avoid_: доступное время, таймслот

**Свободный слот**:
Слот, который не пересекается ни с одной встречей.
_Avoid_: свободное время, окно

**Окно записи**:
Ближайшие 14 календарных дней, в пределах которых гость может выбрать слот.
Каждый день окно сдвигается на день вперёд.
_Avoid_: горизонт, период бронирования

**Рабочие часы**:
Время, в которое могут проходить встречи: понедельник–пятница, 10:00–18:00 по
Москве.
_Avoid_: график, часы приёма

## Поверхности

**Главная страница**:
Входной экран сервиса: название, описание, кнопка «Записаться» и блок возможностей.
Данных календаря не показывает.
_Avoid_: лендинг, домашняя страница

**Страница бронирования**:
Поверхность, где гость выбирает тип встречи, свободный слот, подтверждает
бронирование и видит подтверждение.
_Avoid_: страница записи, форма записи

**Страница владельца**:
Поверхность, где владелец создаёт типы встреч и видит предстоящие встречи всех
типов по возрастанию начала.
_Avoid_: админка, кабинет
