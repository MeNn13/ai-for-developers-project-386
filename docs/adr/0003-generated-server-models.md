# 0003. Серверные транспортные модели с проектным патчем TypeSpec

Для устранения ручного дублирования HTTP-контракта используем серверные модели
из TypeSpec через `@typespec/http-server-csharp@0.58.0-alpha.32` с явным проектным
патчем источника из #56. Непатченный официальный alpha-релиз не проходит нашу
строгую сборку; выбранный подход требует сопровождения патча, но сохраняет
контракт, nullable и warnings-as-errors без ручных правок generated C#.

Изолированный lock-файл сохраняет проверенный набор зависимостей. Каждая генерация
проверяет версию и полные исходники emitter, применяет required/nullable/DateOnly,
выбирает модели и helpers и исключает MVC-инфраструктуру. Артефакты коммитятся и
проверяются повторной генерацией в отдельный каталог. Domain и Application
сохраняют независимость согласно ADR-0002; преобразования остаются в HTTP-слое.

Патч не означает совместимость официального релиза без изменений. При появлении
upstream-исправлений пересматриваем решение: удалить соответствующие части патча
можно после чистой установки, строгой сборки и прежней матрицы HTTP-conformance
на Windows и Ubuntu. Автоматическая смена генератора не предусмотрена.
Порядок обновления записан в `contract/server/README.md`.
